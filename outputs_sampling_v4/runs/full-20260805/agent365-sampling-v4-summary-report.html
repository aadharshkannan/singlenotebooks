Metric Definitions

  • Selected-only absolute aggregate rate error = |selected pass rate - census|.
  • IDW aggregate error = |observed+imputed population mean - census|.
  • Fraction saved = 1 - (selected count / population count).
  • Concept coverage = covered concepts / total concepts in the run aggregate.
  • Deterministic expected labels are pseudo-judge outputs; adaptive methods are not design-unbiased estimators.

Sampling Methods

Selection versus estimation: Random, MinHash, and embedding are selection methods under matched exact budgets. Same-agent IDW is a post-freeze estimator applied only to embedding unjudged units.

What this shows: each method explainer is an inline architecture view of persisted operations; none rely on external assets.

Random token-priority selection

  1. Build an exact token budget from persisted budget manifests.
  2. Rank sessions deterministically from the paired randomized replay order.
  3. Pack maximal whole sessions without splitting.
  4. Seal labels until membership is frozen.
Estimation modeSelected-only
Budget ruleExact token budget is authoritative
Fill behaviorNo separate adaptive fill stage

MinHash LSH 32x4 selection

  1. Generate a 128-value MinHash signature split into 32 bands of 4 rows.
  2. Propose sessions from candidate collisions under exact budget.
  3. If no candidates collide, mark proposal as novel/no-candidate.
  4. Do not execute exhaustive full-corpus fallback scans.
LSH shape128 values; 32 bands x 4 rows
No-candidate handlingNovel proposal; no exhaustive scan
Estimation modeSelected-only

Embedding selection

  1. Embed sessions under the same exact budget process.
  2. Select native embedding proposals with deterministic budget fill.
  3. Freeze membership before any outcome estimation.
  4. Track observed coverage and unjudged units for IDW stage.
Estimation modeSelected-only baseline + IDW extension
Label handlingLabels remain sealed until membership freeze
Budget packingMaximal whole-session packing

Same-agent IDW estimation

  1. After membership freeze, impute only unjudged units.
  2. Use same-agent donor neighborhoods with inverse-distance weighting.
  3. Fallback to prior only when no donor is available.
  4. Combine observed and imputed means into aggregate rate estimate.

Caveats

  • The selection stage did not compute IDW; IDW was applied after membership freeze.
  • Adaptive methods are not design-unbiased estimators in this setup.
  • Expected labels are pseudo-judge outputs, not human gold labels.
  • Synthetic corpus scope may not transfer to production distributions.
  • Same-agent donor fallback can increase prior-driven estimates when donor coverage is sparse.
  • Only three paired outcome repetitions were run for this bundle.
  • Empirical low/high are observed replay ranges, not confidence intervals.
